Site Credits

Built By Students

This website was designed and developed by Damon Lin, President of the Mepham Robotics Club and Captain of Team 77628A (2025-2029).

Technologies Used

  • HTML5 & CSS3 — Semantic structure and custom styling
  • Vanilla JavaScript — Interactive features, animations, and search
  • Flask — Python web framework for server-side rendering
  • Google Fonts — Balsamiq Sans & Space Mono typography
  • Givebutter — Donation processing widget
  • Vercel — Deployment and hosting

Design Credits

  • Design System: Custom neo-brutalist design with maroon & gold theme
  • Icons: Lucide iconography + inline SVGs
  • Animations: CSS keyframes & IntersectionObserver-based reveals
