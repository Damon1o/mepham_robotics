Engineering Notebook

Our design process, testing logs, and iteration notes — documenting the journey.

Latest Entries

Engineering notebook entries will be uploaded here as the season progresses. Each entry follows the design process: Identify → Brainstorm → Select → Build → Test → Iterate.

Every notebook entry includes:

  • Date & Attendees — who was there
  • Objective — what we set out to accomplish
  • Process — step-by-step work done
  • Results — what happened (including failures)
  • Reflection — what we learned and next steps
  • Photos/Sketches — visual documentation

Design Process Overview

Identify

Define the problem the mechanism needs to solve based on game analysis.

Brainstorm

Generate multiple solution concepts with sketches and pros/cons.

Select

Choose the best approach using a decision matrix weighted by priorities.

Build

Prototype and construct the selected design with careful documentation.

Test

Evaluate performance with measurable metrics and driver feedback.

Iterate

Refine based on test results — repeat until competition-ready.
